IQScore Fun - setup
1. Domain is set to iqscore.fun in all files. If you pick a different domain, search & replace iqscore.fun everywhere. Create the mailbox contact@iqscore.fun (or change the email) before applying to AdSense.
2. Upload all files to any static host (Cloudflare Pages, Netlify, GitHub Pages - all free) and connect your domain.
3. Apply for Google AdSense with your domain. When approved, paste the AdSense script in the <head> marked in each page and ad units in the 'AD SLOT' spots. Update ads.txt.
4. Add Google Search Console and submit sitemap.xml.
5. Keep adding articles (2-3 per week) to grow search traffic.
